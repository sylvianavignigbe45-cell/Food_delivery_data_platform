# Food Delivery Data Platform

## Project Overview

This project is an end-to-end Data Engineering project that simulates a food delivery data platform.

The goal is to collect, clean, transform, store, and analyze data generated by a food delivery business.

## Business Problem

A food delivery company generates large amounts of data from customers, restaurants, drivers, orders, and deliveries.

This project demonstrates how raw operational data can be transformed into useful and reliable information for business analysis.

## Data Pipeline

Raw Data
→ Data Cleaning
→ Data Transformation
→ SQLite Database
→ SQL Analysis
→ Business Insights
